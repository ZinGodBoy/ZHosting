# ZHosting Support

## 📌 Trạng thái dự án

ZHosting hiện là **frontend prototype / demo**.

Một số dữ liệu trong giao diện là dữ liệu minh họa, bao gồm:

- Giá.
- Uptime.
- Latency.
- Node status.
- Testimonials.
- Account data.
- Billing data.

## 🐛 Báo lỗi

Khi báo lỗi, hãy cung cấp:

1. URL hoặc page.
2. Browser + version.
3. Desktop/mobile.
4. Các bước tái hiện.
5. Kết quả mong đợi.
6. Kết quả thực tế.
7. Console error nếu có.
8. Screenshot/video nếu cần.

## 🔐 Báo lỗi bảo mật

Không đưa vulnerability nhạy cảm vào issue công khai.

Ưu tiên GitHub Security Advisory:

https://github.com/ZinGodBoy/ZHosting/security/advisories/new

Xem thêm: [SECURITY.md](SECURITY.md).

## 🧩 Feature request

Một feature request tốt nên có:

- Vấn đề cần giải quyết.
- Người dùng bị ảnh hưởng.
- Giải pháp đề xuất.
- Tác động UX.
- Security impact nếu có.

## 💬 Khi cần hỗ trợ phát triển

Kiểm tra trước:

- README.
- Architecture.
- Testing.
- Security.
- Changelog.

## ⚠️ Production

Không gửi password thật, API key, access token, payment information hoặc dữ liệu khách hàng khi yêu cầu hỗ trợ.
