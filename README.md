# ZHosting

Website giới thiệu dịch vụ **Minecraft Hosting · Web Hosting · VPS · Web Development**.

## Demo
Repository: https://github.com/ZinGodBoy/ZHosting

## Công nghệ
- HTML5 semantic
- CSS3 responsive + glassmorphism
- JavaScript ES6
- Google Fonts
- Không phụ thuộc framework

## Tính năng
- Hero section với trạng thái hệ thống
- 4 nhóm dịch vụ
- Bảng giá có chuyển tháng/năm
- Responsive mobile menu
- Scroll reveal animation
- FAQ accordion
- CTA liên hệ
- Thiết kế mobile-first và GitHub Pages friendly

## Cấu trúc
```
ZHosting/
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   └── js/
│       └── app.js
├── README.md
└── AI_LOG.md
```

## Chạy local
Mở `index.html` trực tiếp hoặc dùng Live Server trong VS Code.

## GitHub Pages
Vào **Settings → Pages**, chọn branch `main` và thư mục `/ (root)`, sau đó lưu. GitHub sẽ tạo URL Pages cho repository.

> Lưu ý: Giá, email và thông tin dịch vụ trong giao diện là nội dung demo và cần thay bằng dữ liệu kinh doanh thực tế trước khi sử dụng.
