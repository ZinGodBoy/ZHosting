# ZHosting v1.4.0

**Release:** Frontend Hardening & Admin Control Plane  
**Date:** 2026-11-14  
**Status:** Release Candidate

## Summary

v1.4.0 consolidates the current frontend architecture after the Account Center and Admin Center expansion. The release focuses on stability, security-aware UX, performance and regression prevention.

## Highlights

- Account Center with command palette, workspace navigation and account tools.
- Admin Center with user directory, analytics, audit feed, session controls and global search.
- Trusted Admin Device Gate using Web Crypto + IndexedDB.
- Shared ZHosting logo and favicon.
- PBKDF2-SHA-256 demo password records with legacy migration.
- Session idle/absolute timeout, revocation and login throttling.
- Adaptive performance runtime and reduced-motion support.
- Lifecycle-safe timers and navigation hardening.
- CSV export hardening against spreadsheet formula injection.

## Important security boundary

ZHosting is still a static/frontend prototype. The trusted admin device is a browser-bound control, not proof of physical-machine ownership. Production authorization must move to a backend with server-side sessions, RBAC, device enrollment/revocation and tamper-resistant audit logging.

## Regression fixes

- Removed first-user automatic admin promotion.
- Removed duplicated performance runtime on 404.
- Prevented invalid hash anchors from throwing.
- Prevented hidden-tab session/admin timers from doing unnecessary callback work.
- Added cleanup for lifecycle-bound timers.
- Hardened admin search behavior.
